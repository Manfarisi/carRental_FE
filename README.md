# 🚗 Car Rental Frontend (React)

Frontend application for a **Car Rental System**, built using **React**.
This application focuses on **user interface development**, **API integration**, and **real-time communication** between car owners and users.

---

## 📌 Overview
The Car Rental Frontend allows users to browse available cars, manage bookings, and communicate directly with car owners through a real-time chat feature.

---

## 🚀 Features
- Browse and view available cars
- Car management (Create, Update, Delete) for owners
- Car booking interface for users
- Real-time chat between owner and user
- JWT-based authentication handling
- Responsive and user-friendly UI
- REST API integration using Axios
- Toast notifications for user actions

---

## 🛠️ Tech Stack
- React
- Axios
- Tailwind CSS
- React Router
- Firebase (real-time chat)

---

## 🔐 Authentication
- Uses JWT for handling authentication tokens
- Protected routes for owners and users
