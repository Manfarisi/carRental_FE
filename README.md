# 🚗 Car Rental Frontend (React)

A **frontend application** for a Car Rental system built using **React**.
This application focuses on **user interface development**, **API integration**, and **real-time chat** between car owners and users.

---

## 📌 Overview
The Car Rental Frontend allows users to browse available cars, manage bookings, and communicate directly with car owners through a chat feature.

---

## 🚀 Features
- View available cars
- Create, update, and delete car data (owner)
- Car booking interface
- Real-time chat between owner and user
- Responsive user interface
- API integration using Axios

---

## 🛠️ Tech Stack
- React
- Axios
- Tailwind CSS / CSS
- Firebase (for chat)
